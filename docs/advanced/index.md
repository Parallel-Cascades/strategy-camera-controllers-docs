# Advanced Features

The following advanced features are available across one or more camera controllers.

| Feature | Supported Cameras | Description |
|---|---|---|
| [Camera Bounds](./camera-bounds.md) | All three | Constrain camera movement to a defined rectangular play area |
| [Automatic Elevation Adjustment](./auto-elevation.md) | All three | Lift the camera above terrain and obstacles automatically |
| [Cursor System](./cursor-system.md) | All three | ScriptableObject-based cursor swapping as the camera changes state |
| [UI Pause Integration](./ui-integration.md) | All three | Pause camera input from UI Toolkit or uGUI |
| [Input Remapping](./input-remapping.md) | All three | Remap all controls via the Input System Actions editor |
